## 功能
- **TPA 传送指令**：无需目标玩家同意，直接传送到对方位置。
> 使用方式：
> ```
> /tpa <玩家名>
> ```
- **返回指令**：可以回到上一次死亡位置。
> 使用方式：
> ```
> /back
> ```
